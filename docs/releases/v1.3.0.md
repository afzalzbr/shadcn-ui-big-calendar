# shadcn-big-calendar v1.3.0

Version 1.3.0 adds first-class calendar and time-row sizing, an interactive demo, and reliable header alignment when switching between compact and spacious layouts.

## Highlights

- Set the calendar height with the new `height` prop.
- Set exact Week and Day time-row heights with the new `rowHeight` prop.
- Use pixel numbers or any valid CSS length, such as `"3rem"` or `"clamp(2.5rem, 5vw, 4.5rem)"`.
- Explore seven density presets and a custom 16–240px field in the new `/features/row-height` demo.
- Switch row heights at runtime without stale scrollbar compensation or header/grid misalignment.

## Installation

```bash
npm install shadcn-big-calendar@1.3.0
```

Import the package styles once in your application:

```tsx
import "shadcn-big-calendar/styles";
```

## Sizing API

```tsx
<ShadcnBigCalendar
  localizer={localizer}
  events={events}
  height={620}
  rowHeight={48}
/>
```

Numbers are interpreted as pixels. CSS length strings are also supported:

```tsx
<ShadcnBigCalendar rowHeight="3rem" />
```

If both `height` and `style.height` are supplied, `style.height` takes precedence. Omitting `rowHeight` preserves React Big Calendar's default sizing behavior.

## Fixes

- Explicit row heights now render at the requested size, including compact values below 40px.
- Header columns remain aligned with time-grid columns when a vertical scrollbar appears or disappears.
- Runtime `rowHeight` changes trigger the calendar's overflow recalculation.

## Compatibility

- No breaking API changes.
- Existing calendars work unchanged when the new props are omitted.
- Compatible with the existing React 18 and React Big Calendar peer dependency ranges.
